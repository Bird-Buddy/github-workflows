Walk these precondition classes and flag any the PR neither includes nor mentions, stating EXACTLY what a human must verify: ORDERING (something must land/deploy/publish/migrate first); PERSISTED SHAPE (data/artifacts/state already written that this now reads/writes differently); CONSUMER COMPATIBILITY (callers, services, or clients this diff cannot see); CONFIGURATION (a var/flag/credential/permission that must exist first); REPEAT SAFETY (retry/rerun/concurrent/partial-failure). A class with nothing real behind it is NOT a finding.
   🔵 Suggestion — up to 3 concrete non-blocking improvements on code the PR touches.
   Keep 🔴/🟠 low-noise: no style/nits, no scratch/experiment code, no generated/fetched artifacts, no pre-existing issues. Unsure 🔴 -> 🟠; unsure 🟠 -> drop.
